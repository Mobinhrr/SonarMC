# SonarMC Website

A polished, responsive SonarMC server landing page with:
- Persian default + English language toggle
- Click-to-copy server IP
- Shop / Wiki / Discord navigation
- Smooth reveal and hover animations
- Responsive mobile layout
- SonarMC logo + Minecraft-inspired hero artwork

## Customize

Open `script.js` and edit:

```js
const CONFIG = {
  serverIp: "5.57.34.22",
  shopUrl: "#shop",
  wikiUrl: "#wiki",
  discordUrl: "#discord"
};
```

Replace those values with your real server IP and links.

## Run

Open `index.html` in a browser, or upload the whole folder to your web host.
